# Vídeo animado / explicativo (motion, explainer, SaaS, institucional)

## Princípios
- **Explicar é simplificar sem mentir.** Uma ideia complexa vira uma sequência de ideias simples, uma por cena.
- **Escreva para a imagem.** Animação pode mostrar qualquer coisa — use isso. Toda frase de locução deve sugerir uma imagem; se não sugere, provavelmente é abstrata demais.
- **Locução e imagem se complementam**, não se repetem. A imagem mostra o *quê*; a locução diz o *porquê* (ou vice-versa).
- **Metáfora visual** é a ferramenta principal: um conceito invisível (dados, segurança, processo) vira um objeto/ação visível.

## Durações
| Uso | Duração | Palavras (~2,4/s, locução calma) |
|---|---|---|
| Explainer de produto (site/landing) | 60–90 s | 140–210 |
| Explainer curto para social | 30–45 s | 70–110 |
| Institucional / manifesto | 60–120 s | 140–280 |
| Tutorial / onboarding | 1–3 min | por passo |
| Vídeo de feature (SaaS) | 20–45 s | 50–100 |

Explainers acima de 2 min perdem muita gente — prefira cortar.

## Estrutura clássica de explainer
1. **Gancho / problema (≈15%)** — o público se reconhece. Um personagem ou situação concreta.
2. **Agitação / custo do problema (≈10%)** — o que acontece se nada mudar.
3. **Solução (≈10%)** — apresenta o produto/ideia em uma frase.
4. **Como funciona (≈40%)** — 3 passos ou 3 benefícios no máximo. Mostre, não liste.
5. **Prova / resultado (≈10%)** — número, cliente, transformação.
6. **CTA (≈15%)** — ação + marca + URL/handle.

Variações: **manifesto** (crença → tensão com o mundo → visão → convite); **jornada** (personagem antes → descoberta → depois); **pergunta-resposta** (para educativo); **"o que acontece quando você…"** (para SaaS, mostrando o fluxo na UI).

## Vídeo de produto SaaS
- Mostre a interface em ação, não prints parados. Descreva o que acontece na UI cena a cena (clique, campo preenchido, resultado aparecendo).
- Foco no resultado do usuário ("relatório pronto em 2 cliques"), não na tela.
- Simplifique a UI no roteiro: indique quais elementos destacar e quais esconder.
- Uma feature por vídeo curto; vídeo de visão geral pode ter até 3.

## Escrita para animação
- Uma cena = uma ideia = 3–8 s.
- Indique no visual: personagens, cenário, ação principal, transição para a próxima cena (morph, match cut, zoom, wipe), elementos de texto/ícone.
- Pense em **continuidade visual**: um objeto que se transforma no próximo conceito costura a narrativa melhor que corte seco.
- Marque **beats** de som (SFX, batida da trilha) nos momentos de revelação.
- Texto na tela: palavras-chave e números, não frases inteiras.
- Locução: tom conversado, frases curtas, pausas indicadas com "(pausa)" quando importam.
- Evite: "Apresentamos…", "A solução completa para…", começar pela marca, enumerar 7 features.

## Institucional / marca
Fale de pessoas e de propósito antes de fatos sobre a empresa. Um número forte vale mais que uma lista de conquistas. Termine com assinatura (slogan/tagline) curta e memorável.
